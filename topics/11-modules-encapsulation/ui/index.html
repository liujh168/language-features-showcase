主题 11：模块与封装

同一个 utils 模块，六种可见性机制 · 公开 API / 私有实现

本题要做什么

  1. 实现 greet() / area() / makeUser() 公开接口
  2. decorate() 内部实现必须对使用者不可见
  3. User 的内部字段外部不可直接访问

预期输出（六语言逐字节一致）
