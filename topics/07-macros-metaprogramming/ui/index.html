主题 07：宏与元编程 Macros & Metaprogramming

square(7) 小题大做，只为看清“谁在什么层面做代码变换” · 学习对比用

本题要做什么

计算并打印 square(7) 和 cube(3)。每个语言都动用自家最高阶的元编程设施（或展示它没有）。 六个语言输出逐字节一致。

代码对比（点击切换语言）

预期输出（六个语言逐字节一致）
square(7) = 49
cube(3) = 27

元编程层次

语言设施变换层面
C++（原始）#define 宏纯文本替换，最危险
C++（现代）模板 + constexpr编译期，有类型，正道
Rustmacro_rules! / 过程宏token 树，卫生宏
Python装饰器 / 元类运行期，函数类皆对象
Go无宏（go:generate）刻意反元编程
TS无宏元编程在类型层（类型体操）

教学要点

1. C 宏经典坑：SQUARE(a+b) 展开成 a+b*a+b——文本替换不懂优先级，必须 ((x)*(x))。
2. Rust $x:expr 匹配的是语法单元，卫生宏不会意外捕获变量——文本宏的硬伤被根治。
3. 运行期元编程（Python 装饰器）每次调用走包装层；编译期元编程零运行时成本。
