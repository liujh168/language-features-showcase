主题 12：异步生态进阶

三任务完成竞赛 + 汇合 · async/await 只是语法，运行时才是本体

本题要做什么

  1. fast(10ms) / medium(100ms) / slow(300ms) 三个任务同时开跑
  2. 按完成顺序输出（不是启动顺序）
  3. 全部结束后打印 all settled

预期输出（六语言逐字节一致）

task fast finished
task medium finished
task slow finished
all settled
