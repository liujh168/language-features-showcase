Dog/Cat 多态一道题，三种类型哲学的终极对比 · 学习对比用

本题要做什么

Dog（woof）、Cat（meow）统一调用 speak()。 六个语言输出逐字节一致，但“谁算 Animal”的答案完全不同。

代码对比（点击切换语言）

预期输出（六个语言逐字节一致）
dog says: woof
cat says: meow

三种类型哲学

语言哲学接口声明分发方式
C++名义类型抽象基类（显式继承）vtable 动态
Rusttrait（混合）trait + impl（实现与类型分离）dyn 动态 / 泛型静态
Go结构化interface（隐式满足）接口值动态
TS结构化interface（可显可隐）擦除后动态
Python鸭子类型无（Protocol 仅检查器）属性查找动态

教学要点

1. 名义类型：类型身份由声明决定（C++ 不继承 Animal 就不是）；结构化类型：由形状决定（长得像就是）。
2. Go 接口的灵魂：由使用者定义——小接口 + 隐式满足，测试时随便 mock。
3. Rust 一个 trait 两种分发：dyn（运行时灵活）vs 泛型（编译期零成本），开发者自己权衡。
