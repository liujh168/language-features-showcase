主题 04：错误处理 Error Handling

“错误是值”派 vs “错误是控制流”派的正面对撞 · 学习对比用

本题要做什么

解析正整数 + 安全除法，成功失败各一次。失败原因必须出现在输出里， 六个语言输出逐字节一致。

10 / 2 = 5

教学要点

1. Rust/Go 把失败写进类型签名，想无视都难；C++/Python/TS 的异常穿透调用栈，写起来爽但调用方一无所知。
2. C++ 现代趋势是回归“错误是值”：std::expected（C++23）就是 Rust Result 的表亲。
3. TS 的坑：Number("abc") 返回 NaN 而不是抛错——必须自己写校验主动 throw。
