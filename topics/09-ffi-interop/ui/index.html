同一道题：各语言调用 C 标准库的 strlen · 工程量从一行到五步

本题要做什么

  1. 在语言内声明/加载 C 函数 strlen
  2. 对两个字符串求长度，输出结果
  3. 体会五种 FFI 机制的工程量差异

代码对比（点击切换语言）

预期输出（五语言逐字节一致）
strlen("hello") = 5
strlen("modern languages") = 16

工程量对比

语言机制步骤一句话
C++extern "C"0 步直接调C 的近亲
Rustextern 块 + unsafe声明即调FFI 一等公民
Pythonctypes2 行胶水之王
Gosyscall.NewLazyDLL声明+调用仅 Windows；跨平台用 cgo
