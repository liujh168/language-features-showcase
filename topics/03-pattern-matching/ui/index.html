主题 03：模式匹配 Pattern Matching

整数分类一道题，看清六种语言对“模式匹配”的态度 · 学习对比用

本题要做什么

classify(n)：0 → "zero"，1 → "one"，负数 → "negative"，偶数 → "even"，否则 "odd"。 对 0、1、-3、42、7 各调一次，六个语言输出逐字节一致。

代码对比（点击切换语言）

预期输出（六个语言逐字节一致）
classify(0) = zero
classify(1) = one
classify(-3) = negative
classify(42) = even
classify(7) = odd

差异速览

语言现状关键差异
Rustmatch 王牌特性可返回值；守卫；编译器强制穷尽
Pythonmatch-case（3.10+）语法最像 Rust；但不强制穷尽
Go无无 tag switch = 带糖 if-else 链；默认不贯穿
C++无（C++23/26 仍无）现实就是 if-else 链；P1371 提案拉锯中
TS无（TC39 提案阶段）switch 离散值 + if 守卫

教学要点

1. 模式匹配对值的形状解构（枚举/元组/结构体），条件分支只比布尔——本例只是守卫热身，Rust 换 enum 解构才是 match 真威。
2. 穷尽性检查是安全网：Rust 漏分支编译报错；别语言的 default 写不写全靠自觉。
3. Go/C++ 社区长期拒绝模式匹配——“if-else 就够了”，这个争论本身值得读。
