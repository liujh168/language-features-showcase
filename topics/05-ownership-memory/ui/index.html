主题 05：所有权与内存 Ownership & Memory

资源生命周期管理——唯一一个六语言答案本质不同的主题 · 学习对比用

本题要做什么

资源对象：创建即 acquire，使用，离开作用域时必定 release（无论是否异常），最后打印 done。 六个语言输出逐字节一致，但机制天差地别。

差异速览

语言内存哲学确定性释放机制释放时机
Rust所有权（编译期强制）Drop trait作用域结束，编译器保证
C++RAII（程序员自觉）析构函数作用域结束，自觉保证
GoGCdefer函数退出时（LIFO）
PythonGCwith 上下文管理器with 块结束（任意块级）
TSGCtry-finally（手动）finally 块，全靠自己写

教学要点

1. GC ≠ 释放不可控：文件句柄、锁、连接不该等 GC，六种语言都有确定性清理机制。
2. Rust 所有权 = RAII + 编译期强制：Drop 就是析构函数，但 move 语义消灭了 C++ 的拷贝陷阱（double free 编译期就是错）。
3. defer 在函数级作用域；with 是任意块级且语法最干净；JS 最原始——背后是“对象死亡时间语言拒绝承诺”的设计。
